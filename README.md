# online_deans_office
Проект III Межрегионального хакатона UmirHack, кейс "Онлайн-деканат" от ЦентрИнвест. Цифровой секретарь, который читает фото студенческого документа и отвечает на вопрос со ссылкой на правила.

----
Как запускать
cmd_1: uvicorn backend.main:app --reload
cmd_2: streamlit run ui/app.py

Что нужно учесть
- Запускать нужно в двух разных окнах терминала, оба должны работать одновременно. В каждом сначала активируйте окружение: .venv\Scripts\activate .
- Порядок такой: сначала бэкенд, потом фронт.
- Проверить, что бэкенд жив, можно в браузере по адресу http://127.0.0.1:8000/health. Должно вернуться {"status":"ok"}. А по адресу http://127.0.0.1:8000/docs FastAPI сам показывает интерактивную документацию всех эндпоинтов.
- Один раз перед запуском: pip install -r requirements.txt. Все пакеты в нём перечислены, не хватает только того, что нужно pipeline.py (OCR и так далее), если он что-то подключает.
- Если порт 8000 занят, сервер скажет об этом. Тогда запустите на другом (--port 8001) и поправьте API в ui/app.py.
- Максимальный размер фото по умолчанию 10 МБ. Чтобы изменить, перед запуском бэкенда задайте переменную окружения (PowerShell: $env:MAX_UPLOAD_MB=20) и поменяйте maxUploadSize в .streamlit/config.toml на то же число.
- Регистрации нет: при первом заходе страница выдаёт посетителю случайный код и добавляет его в адрес (?s=...). Каждый видит только свои задачи. Кто откроет ту же ссылку, увидит ту же историю, поэтому ссылкой с ?s= лучше не делиться.
- Если после обновления кода бэкенд падает с ошибкой про столбец owner, значит data/app.db создана старой версией. Остановите сервер и удалите этот файл, база создастся заново.
- За один раз страница отправляет не больше 10 фото (MAX_FILES в ui/app.py). Бэкенд держит у одного посетителя не больше 10 незавершённых задач, лимит меняется переменной окружения MAX_ACTIVE_JOBS. Файл проверяется по содержимому (Pillow): принимаются только настоящие jpg, png, webp и PDF. PDF сразу при загрузке превращается в одну PNG-картинку (backend/pdf.py, библиотека pypdfium2, 300 dpi, до 3 страниц, меняется переменной окружения MAX_PDF_PAGES), поэтому pipeline.py по-прежнему получает только картинку; исходный PDF не сохраняется.
- Задачи и фото старше часа удаляются автоматически: при старте сервера и затем раз в 5 минут (backend/cleanup.py). Меняется переменными окружения JOB_TTL_MINUTES и CLEANUP_EVERY_MINUTES. Если меняете срок, поправьте и подпись на странице в ui/app.py.
- Лог бэкенда пишется в консоль и в файл data/logs/app.log (до 5 МБ, плюс 3 старых файла). Там входящие запросы, отказы с причиной и ошибки pipeline с полной трассировкой. Частые опросы страницы (GET /jobs) видны только с LOG_LEVEL=DEBUG. session_id, IP, имена файлов и вопросы в лог не пишутся. Чтобы uvicorn не дублировал запросы в консоли, запускайте его с --no-access-log.
