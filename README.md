# online_deans_office
Проект III Межрегионального хакатона UmirHack, кейс "Онлайн-деканат" от ЦентрИнвест. Цифровой секретарь, который читает фото студенческого документа и отвечает на вопрос со ссылкой на правила.

----
Как запускать
cmd_1: uvicorn backend.main:app --reload
cmd_2: streamlit run ui/app.py

Что нужно учесть
- Запускать нужно в двух разных окнах терминала, оба должны работать одновременно. В каждом сначала активируйте окружение: .venv\Scripts\activate.
- Порядок такой: сначала бэкенд, потом фронт.
- Проверить, что бэкенд жив, можно в браузере по адресу http://127.0.0.1:8000/health. Должно вернуться {"status":"ok"}. А по адресу http://127.0.0.1:8000/docs FastAPI сам показывает интерактивную документацию всех эндпоинтов.
- Один раз перед запуском: pip install -r requirements.txt. Все пакеты в нём перечислены, не хватает только того, что нужно pipeline.py (OCR и так далее), если он что-то подключает.
- Если порт 8000 занят, сервер скажет об этом. Тогда запустите на другом (--port 8001) и поправьте API в ui/app.py.

----
OCR (backend/ocr)
Распознавание текста: PaddleOCR PP-OCRv5, русская модель (eslav_PP-OCRv5_mobile_rec), на CPU, без внешних API.
Поворот всего листа включён, разворот отдельных строк выключен: иначе на печатных договорах половина строк читается задом наперёд.
Детектор мобильный, но смотрит картинку до 1920 px по длинной стороне и с более мягким порогом рамки — плотные договоры меньше режутся на куски.
Принимает JPG, PNG, WEBP и PDF (до 15 МБ, до 10 страниц). Отдаёт чистый текст и JSON со строками, уверенностью и рамками на исходном фото.

Установка (входит в pip install -r requirements.txt):
- paddlepaddle закреплён на 3.2.2: в 3.3.0 на CPU сломан запуск моделей PaddleOCR.
- Нужен 64-битный Python 3.9–3.13 и процессор с AVX (любой Intel/AMD последних лет).
- При первом запуске модели скачиваются сами (около 100 МБ) в папку ~/.paddlex.

Запуск из консоли:
python -m backend.ocr путь/к/справка.jpg
python -m backend.ocr папка_с_документами --out data/ocr
Для каждого документа появятся <имя>.txt и <имя>.json. Шаблон JSON описан в backend/ocr/__init__.py.

Из кода:
from backend.ocr import run_ocr, OcrError
result = run_ocr("справка.jpg")   # result["text"] - текст, result["pages"][0]["lines"] - строки с рамками
OcrError несёт текст для студента (плохой формат, пустой файл, текст не прочитан).

Тесты: python -m pytest tests -q (тесты с моделью пропускаются, если PaddleOCR не установлен).

Проверка руками (отдельная страница, не сайт деканата):
streamlit run ui/ocr_check.py
Загрузите фото или нажмите «Проверить на примере». Страница покажет текст, рамки на снимке и сверит записанные txt/json с результатом.
