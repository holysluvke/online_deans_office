# Сдача (issue #13)

## Порядок

1. **За 3 часа до дедлайна — заморозка.** После неё только багфиксы с цифрами «до/после» из `run_batch`.
2. Свежий клон репозитория, чистое окружение: `pip install -r requirements.txt`, один раз с сетью (модели скачиваются).
3. `python -m pytest tests -q` — зелёный.
4. `python tools/run_batch.py --mode gold` — «УРОВЕНЬ A: ОК».
5. `python tools/run_batch.py --mode ocr --source png --no-cache` — запомнить цифры (это итоговые метрики на открытых данных). То же для `--source pdf`.
6. Когда организаторы выдадут закрытый набор: положить в `data/closed/`, запустить
   `python tools/run_batch.py --mode ocr --source png --data data/closed --out results.json`,
   убедиться, что в консоли нет «ФОРМАТ results.json НЕВЕРЕН», посмотреть секунды в `results.meta.json`.
7. Коммитим только итоговый `results.json`. Остальные `results*.json` и `*.meta.json` не коммитим.
8. Отключить сеть и один раз пройти демо руками: `uvicorn backend.main:app --no-access-log` и `streamlit run ui/app.py`.
